# Introduction

Welcome to the Tripous Framework documentation.

Tripous is a .NET framework for building data-centric applications, desktop applications, business systems and services.

The documentation is divided into two major parts:

- Conceptual documentation
- API reference documentation

The conceptual documentation explains the architecture, design principles and major framework components.

The API reference documentation is generated directly from source code and XML comments.

If you are new to the framework, start with:

- [Getting Started](getting-started.md)
- [What Is Tripous?](tripous-framework/what-is-tripous.md)
- [Design Philosophy](tripous-framework/design-philosophy.md)
- [Framework Layers](tripous-framework/framework-layers.md)
