# Tripous.Avalon

Tripous.Avalon is a cross-platform .NET application framework
built with [Avalonia UI](https://avaloniaui.net/) and focused on structured desktop business applications.

The project follows a metadata-driven architecture
centered around data modules, table definitions,
automatic UI generation, SQL-based data access,
master-detail workflows, and high-productivity data-entry forms.

Main goals of the project:

- fast development of desktop business applications
- deterministic and understandable architecture
- minimal framework magic
- strong SQL and relational database orientation
- reusable business modules and UI components
- support for large data-entry style applications
- cross-platform desktop deployment

The framework is heavily inspired by:

- structured RAD application design
- practical enterprise application workflows

Tripous.Avalon is currently an active exploration
and long-term framework project.
