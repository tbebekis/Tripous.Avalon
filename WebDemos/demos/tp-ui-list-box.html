tp.ListBox

A virtual-scroller based list-box control. It supports primitive item arrays, object arrays with ListDisplayField and ListValueField, and large lists rendered through tp.VirtualScroller.

Click any item. The log shows SelectedIndex, SelectedValue, and the selected item text. The large list verifies that only visible rows are rendered while the list can contain many items.
