tp.ImageSlider

An image slider.

Images are passed as an array of Urls to the Images property.
When AutoCycle is true then images are cycled by an interval defined in AutoCycleMSecs.
The DisplayCycleButtons controls whether the Prev and Next buttons are visible or not.
The SelectedIndex controls and indicates what is the current image.
When ChangeOnClick is true, the default, clicking on an image displays the next image.
