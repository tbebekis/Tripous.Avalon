tp.TextBox

A control class around the HTML input[type=text] element. It provides properties such as MaxLength, Placeholder, RegexPattern, SelectionStart, SelectionEnd, and DOMAutocomplete.

The text box below uses a local AutocompleteList of values: javascript, typescript, script, scriptable, html, and css rules.

Type text to test value changes and autocomplete. Select selects the whole current text. Select 0..4 selects the first four characters, using the text box selection API. Log writes the current control property values below.
