tp.Grid - Thousands of Rows

The tp.Grid is a data grid control.

Some of the features are grouping, summaries, filtering, toolbar and custom buttons, in-place editing, and virtual scrolling.

The tp.Grid uses virtual scrolling instead of paging.

The following example loads 10 thousand rows in a grid. Those rows come from a local tp.DataTable.

Grid columns are created automatically based on tp.DataColumn objects defined in the passed tp.DataTable. In this example the configuration of the grid is done by JavaScript code using grid properties.

Keyboard shortcuts:

Arrow Up / Arrow Down  Move row focus
Arrow Left / Arrow Right  Move cell focus
PageUp / PageDown  Scroll by page
Home / End  Jump to start or end
Enter / F2  Open the in-place editor
Tab  Commit and close the editor
Escape  Cancel and close the editor
