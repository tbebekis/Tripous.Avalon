tp.AutocompleteList

Represents an autocomplete list used with text boxes. The data list can contain primitives or plain JavaScript objects. When the list contains objects, ListDisplayField specifies which property is displayed.

The height of the dropdown list is controlled by the MaxDropdownItems property.
