tp helpers

The Tripous runtime contains many small helper functions under the tp namespace. They keep the rest of the framework readable by centralizing common checks and small operations: type checks, nil/blank checks, array conversion, object inspection, and other small utilities.

These helpers are intentionally small. They are not a replacement for the JavaScript standard library. They exist because framework code repeatedly needs the same safe checks and conversions, and using the same helper everywhere makes behavior easier to read and easier to test.

Type checks

Type helpers answer simple questions in a consistent way: is this value a string, number, date, array, object, plain object, or DOM element?

Nil and blank checks

tp.IsNil() checks for null or undefined. tp.IsBlank() also treats empty or whitespace-only strings as blank.

Object checks

tp.GetPropertyNames() returns useful property names from an object and its prototype chain. tp.Equals() checks whether one object contains the same values as another small object.

Focused helper demos

Some helper areas have their own demos because they are large enough to deserve a single maintenance point. Formatting, object merging, strings, numbers, dates, arrays, units, and URL handling are covered separately.
