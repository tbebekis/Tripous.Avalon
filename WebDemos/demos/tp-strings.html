Tripous Web Demos

Strings

This demo covers the Tripous string helper functions. These helpers are small wrappers around common operations used throughout Tripous code: text checks, case-insensitive comparisons, safe replacement, splitting and joining, padding, generated ids, Base64 encoding, and simple function creation from source text.

URL-related helpers are intentionally not covered here. They have their own Url handling demo. tp.StringBuilder is also handled separately because it is a class with its own behavior.

Checks and search

These helpers answer common string questions: blank text, whitespace characters, HTML-looking text, identifier names, case-insensitive equality, contains, starts with, and ends with.

Transforms

These helpers trim, quote, unquote, insert, replace, remove a trailing comma, truncate text, escape regular expression text, and convert dashed names to camel case.

Splitting and joining

tp.Split(), tp.Chunk(), tp.SplitOnUpperCase(), descriptor splitting, line handling, and join helpers keep common text parsing predictable.

Padding, generation and encoding

This group covers repeat/padding helpers, GUID and random string generation, Base64 encode/decode, and tp.CreateFunction().
