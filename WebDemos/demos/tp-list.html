tp.List

tp.List is an Array subclass with Tripous list operations and optional list events. It can be used like a normal JavaScript array, but it also provides methods such as Add(), Insert(), RemoveAt(), Assign(), AddRange(), FindBy(), and RemoveBy().

Events are disabled by default. Set EventsEnabled = true to receive Changing and Changed events. A batch update can suppress intermediate event notifications by setting Updating = true while multiple changes are made.

Current list

The list contains small objects with Id, Name, and Country properties.

Events and update
