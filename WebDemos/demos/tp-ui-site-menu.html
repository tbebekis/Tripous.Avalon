tp.SiteMenu

The tp.SiteMenu control is a document-like menu with a toggle button for small screens. It supports top menu items, drop-down content panels, and column layouts inside menu item content.

The control is useful for web site navigation and larger document-like menus. It is intentionally simpler than tp.Menu, which targets desktop-style application menus.
