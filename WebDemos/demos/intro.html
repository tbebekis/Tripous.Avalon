Tripous.Web Demos

Tripous.Web Demos is a static showcase site for the JavaScript controls and client-side runtime of Tripous.Web.

Each demo is a plain HTML, CSS, and JavaScript page. The goal is to demonstrate the controls directly, without ASP.NET Core MVC, Razor views, build tools, or server-side dependencies.

These pages are both live demos and usage examples. They show how each control is created, configured, styled, and connected to data or events. The source preview below each demo is intentionally visible, so the behavior remains explicit.

Server-side scenarios, such as forms generated from server definitions, server callbacks, validation, and data persistence, belong to separate ASP.NET Core demo applications.

The purpose of this site is simple: show the controls, show the code, and keep the behavior explicit.
