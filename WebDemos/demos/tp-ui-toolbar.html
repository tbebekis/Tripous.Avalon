tp.ToolBar and tp.ButtonEx

The tp.ButtonEx control is a button class with icon and text. It actually is an anchor element and is used by the tp.ToolBar control.

The tp.ToolBar control is a toolbar. Both classes provide properties to handle button display regarding text and icon.
