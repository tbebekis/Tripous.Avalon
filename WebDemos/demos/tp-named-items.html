tp.NamedItems

tp.NamedItem is a tp.CollectionItem with a Name property. tp.NamedItems is a tp.Collection specialized for named items. It keeps the collection ownership behavior and adds name-based helpers.

The important convenience is that methods such as Add(), Insert(), Remove(), Contains(), IndexOf(), and Find() can work directly with a string name.

Current items

The current collection contains named items. Each item also has a Collection back-reference. 


                        

                            
                            
                        

                    

                    
                    

                        
Add and insert by name

                        

                            Passing a string to Add() or Insert() creates a new
                            named item with that name.
                        

                        

                            
                            
                        

                    

                    
                    

                        
Find by name

                        

                            Contains(), IndexOf(), and Find() accept
                            either an item instance or a name string.
                        

                        

                            
                        

                    

                    
                    

                        
Remove by name

                        

                            Remove("Name") removes the item whose Name matches the
                            supplied string.
