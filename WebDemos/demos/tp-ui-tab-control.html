tp.TabControl

A TabControl.

TabControl uses a ResizeObserver, through tp.ItemBar and tp.ResizeDetector, to detect whether tabs fit in the tab-bar width. It provides three rendering modes: Normal, Toggle, and NextPrev. The user defines the ResponsiveMode, and the control moves from Normal to that mode depending on the width.

You can add a new tab page, remove a page, get or set tab text, and set the selected tab page.
