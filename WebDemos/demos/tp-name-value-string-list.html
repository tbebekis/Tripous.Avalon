tp.NameValueStringList

tp.NameValueStringList stores text lines in Name=Value format. It is useful for compact option lists, old-style setup text, and places where a readable multiline string must become structured name/value data.

The class can be assigned from text, an array of lines, another tp.NameValueStringList, or a tp.Dictionary. Names are matched case-insensitively, while stored line text is kept as strings.

Text input

Assign multiline text to List.Text. Blank lines are ignored.
