tp.WrapObserver

tp.WrapObserver watches registered containers whose child elements may wrap to more than one visual row. It does not use ResizeObserver. Instead, when it is asked to process a container, it compares the child element positions and marks wrap boundaries with CSS classes.

When wrapping is detected, the container receives tp-Wrapped. The first item of each visual row receives tp-WrapFirst, and the last item before a row break receives tp-WrapLast. This is useful for bars, tool strips, and compact layouts that need special styling at wrap boundaries.
