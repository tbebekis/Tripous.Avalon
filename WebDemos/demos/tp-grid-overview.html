tp.Grid - Overview

The tp.Grid is a desktop-like data grid control for tp.DataTable and tp.DataSource data.

It can display normal data rows, group rows, group summary rows, and total summary rows. It supports grouping, summaries, sorting, filtering, in-place editing, lookup columns, boolean columns, date columns, and virtual scrolling.

The grid is organized in panels: toolbar, group panel, column headers, filter row, viewport, summary footer, and bottom horizontal scroll panel.

Try This

  • Drag Department or Country to the group panel.
  • Click a column header to sort ascending, descending, or clear sorting.
  • Type in the filter row under the column you want to filter.
  • Right-click a summary footer cell to change its aggregate function.

Filters

  • Text and lookup columns use contains by default: Gree in Country finds Greece.
  • Numbers use greater-or-equal by default: 40 in Age means >=40.
  • Use =, <>, >, >=, <, or <= for explicit comparisons.
  • Use ? contains, ^ starts-with, and % ends-with for text.
  • Booleans accept true, false, 1, or 0.

Toolbar

  • The Insert button adds an empty row when the grid is editable.
  • The Delete button removes the focused row when deleting is allowed.
  • Edit and Find are command hooks for application handlers and show a note in this demo.
  • Custom applications can add their own toolbar buttons.

Keyboard

Left / Right  Move cell focus
PageUp/Down   Scroll by page
Home / End    Jump to start/end

Escape        Cancel editor
