tp.DataTable

tp.DataTable is the Tripous client-side table model. It deliberately follows the C# DataTable idea: a named table contains tp.DataColumn metadata and tp.DataRow rows. UI controls such as grids can inspect the metadata instead of guessing column titles, data types, formatting, visibility, and required flags from plain objects.

The smallest useful table has a name, a few columns, and one or more rows. A row can be created from an array whose values follow the column order. 

var Table = new tp.DataTable("Customers");
Table.AddColumn({ Name: "Code", Title: "Code", DataType: tp.DataType.String });
Table.AddColumn({ Name: "Name", Title: "Customer", DataType: tp.DataType.String });
Table.AddRow(["C-001", "Acme Ltd"]);
Table.AcceptChanges();
