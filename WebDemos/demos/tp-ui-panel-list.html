tp.PanelList

The tp.PanelList is a list of panels. Only one panel is visible at the same time.

The object passed to the Associate property must provide a SelectedIndex property and a SelectedIndexChanged event. Such an object can automatically control the selected panel of the tp.PanelList.

The Associate object can be passed in the create parameters of the tp.PanelList constructor, or assigned later.
