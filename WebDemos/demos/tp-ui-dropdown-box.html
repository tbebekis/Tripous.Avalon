tp.DropDownBox

The DropDownBox always gets fixed positioning.

The DropDownBox is a resizable dropdown box that can serve any block, inline-block, or flex element, the Associate. It is controlled by an owner object and notifies that owner as it opens and closes.

It recalculates its location so it stays inside the viewport, and closes when the user clicks outside it or scrolls the page.
