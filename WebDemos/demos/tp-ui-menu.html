tp.Menu and tp.ContextMenu

The tp.Menu control represents a desktop-like menu. It uses tp.MenuItem items and supports nested child items.

The tp.ContextMenu control represents a desktop-like local menu. A tp.MenuItem can have text, icon, URL, command, and child menu items.
