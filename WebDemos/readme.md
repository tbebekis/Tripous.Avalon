# Tripous Web Demos

Static client-side demos for Tripous Web JavaScript controls and helpers.

This folder is independent from the ASP.NET Core demo application and from the DocFX documentation site. It contains plain HTML, CSS, and JavaScript pages that can be opened directly in a browser or served as static files.

The Tripous runtime files under `tripous/` are copied from `WebApps/WebApp/wwwroot/tp` by the WebApp MSBuild target. Do not treat those copied files as the source of truth.
